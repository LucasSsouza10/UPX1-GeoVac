# GeoVac: Sistema de gerenciamento de vacinas e gestão de recursos em UBS

Projeto de UPX1 do curso de Análise e Desenvolvimento de Sistemas, 2026, com o tema **Cidades Inteligentes**.

O GeoVac será um aplicativo mobile que conecta cidadãos e órgãos oficiais de saúde para facilitar a gestão vacinal. A plataforma permitirá consultar a carteirinha e o histórico de vacinação, encontrar por geolocalização as Unidades Básicas de Saúde (UBSs) de Sorocaba com estoque disponível para a imunização necessária, acompanhar campanhas futuras e receber alertas personalizados. Também contará com recursos para que os profissionais das UBSs atualizem a disponibilidade de vacinas e gerenciem informações da unidade.
